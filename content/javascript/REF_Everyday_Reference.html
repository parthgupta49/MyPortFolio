1. Does a property exist on this object?

▼

Four ways — each with its own use case.

The in operator — walks the prototype chain
"name" in user;           // true if property exists, including inherited
"toString" in {};         // true — inherited from Object.prototype
hasOwnProperty — own properties only, ignores inherited
user.hasOwnProperty("name");   // true only if OWN property
({}).hasOwnProperty("toString"); // false — inherited, not owned
Modern & safest — Object.hasOwn() (ES2022)
Object.hasOwn(user, "name");     // preferred over user.hasOwnProperty()
// Safer because it works even if `user` was created with Object.create(null)
Undefined check — quick & dirty (but misleading)
if (user.name !== undefined) { ... }
// ⚠️  fails if user.name = undefined was explicitly set
// Use `in` or Object.hasOwn if you need to distinguish "missing" vs "set to undefined"
💡 When to use which: Most code: Object.hasOwn(obj, "key"). Need inherited too: "key" in obj. Never: relying on obj.key === undefined.

2. Iterate over an object

▼
Get keys / values / entries as arrays
const user = { name: "Parth", age: 25, city: "Hyderabad" };

Object.keys(user);     // ["name", "age", "city"]
Object.values(user);   // ["Parth", 25, "Hyderabad"]
Object.entries(user);  // [["name","Parth"], ["age",25], ["city","Hyderabad"]]
Loop over entries — the most common pattern
for (const [key, value] of Object.entries(user)) {
  console.log(key, "=", value);
}
Use HOFs on entries (turn object → array → transform → object)
// Filter out age from a user object
const filtered = Object.fromEntries(
  Object.entries(user).filter(([key]) => key !== "age")
);
// { name: "Parth", city: "Hyderabad" }
⚠️ Never use for...in unless you know what you're doing. It walks the prototype chain and picks up inherited keys. for...of Object.entries() is safer.

3. Update an object immutably

▼

These are the patterns you'll use every day in React. Never mutate — always return a new object.

Change one key
const user = { name: "Parth", age: 25 };

const updated = { ...user, age: 26 };
// { name: "Parth", age: 26 }
// Original `user` is untouched.
Add a new key
const withCity = { ...user, city: "Hyderabad" };
// { name: "Parth", age: 25, city: "Hyderabad" }
Remove a key (using destructuring)
const { age, ...withoutAge } = user;
// withoutAge = { name: "Parth" }
Update a nested key (spread at every level)
const state = { user: { name: "Parth", age: 25 }, theme: "dark" };

const newState = {
  ...state,
  user: { ...state.user, age: 26 }
};
// state is untouched; newState has age: 26
Merge two objects (right side wins on conflicts)
const defaults = { theme: "light", notifications: true };
const custom   = { theme: "dark" };

const merged = { ...defaults, ...custom };
// { theme: "dark", notifications: true }
Deep clone (2022+)
const deepCopy = structuredClone(originalObj);
// Handles Dates, Maps, Sets, circular refs. Not functions.
💡 The mental model: "spread the object I'm keeping, then override what I'm changing." Once this clicks, all React state updates become one-liners.

4. Dynamic keys — accessing/setting properties from a variable

▼
Read a property using a variable
const key = "name";
user[key];        // "Parth"  ← same as user.name
user["name"];     // "Parth"
Set a property using a variable
const key = "email";
user[key] = "parth@example.com";
Create an object with a dynamic key (computed property)
const key = "role";
const value = "engineer";

const obj = { [key]: value };
// { role: "engineer" }

// Especially useful in reduce / grouping:
acc[category] = (acc[category] || 0) + 1;
The "initialize if missing" idiom (very common in reduce)
acc[key] = acc[key] || [];      // if missing, use []
acc[key] ??= [];                // modern equivalent (ES2021)
acc[key].push(item);

5. Destructuring objects

▼
Basic — extract properties into variables
const user = { name: "Parth", age: 25, city: "Hyderabad" };

const { name, age } = user;
// name = "Parth", age = 25
Rename while destructuring
const { name: userName, age: userAge } = user;
// userName = "Parth", userAge = 25
Default values for missing keys
const { name, role = "guest" } = user;
// role = "guest" because user.role doesn't exist
Nested destructuring
const data = { user: { name: "Parth", address: { city: "Hyderabad" } } };

const { user: { name, address: { city } } } = data;
// name = "Parth", city = "Hyderabad"
Destructure in function parameters (super common in React)
function UserCard({ name, age, city = "Unknown" }) {
  return `${name}, ${age}, ${city}`;
}

UserCard({ name: "Parth", age: 25 });   // "Parth, 25, Unknown"

6. Array HOFs — one-line quick reference

▼
MethodWhat it doesReturns
mapTransform each elementNew array (same length)
filterKeep elements matching predicateNew array (≤ length)
reduceCollapse array into single valueAny single value
forEachIterate for side effects onlyundefined
flatMapmap, then flatten one levelNew flat array
All the shapes in one place
arr.map(x => x * 2);                          // [2,4,6]
arr.filter(x => x > 1);                       // [2,3]
arr.reduce((sum, x) => sum + x, 0);           // 6
arr.forEach(x => console.log(x));             // undefined (side effects)
arr.flatMap(x => [x, x * 2]);                 // [1,2,2,4,3,6]
💡 Decision tree:
Same length transformation? → map
Keep some, drop others? → filter
Boil down to one value? → reduce
Side effect only? → forEach

7. Search an array

▼
MethodPurposeReturns
findFirst element matching predicateElement or undefined
findIndexIndex of first matchNumber or -1
someDoes ANY element match?Boolean
everyDo ALL elements match?Boolean
includesContains this exact value?Boolean
indexOfIndex of value (exact match)Number or -1
Find a specific object in an array
const user = users.find(u => u.id === 42);
// user or undefined
Check if any/all elements match
users.some(u => u.isAdmin);      // true if at least one admin
users.every(u => u.age >= 18);   // true only if ALL are 18+
Check for a primitive value
[1, 2, 3].includes(2);         // true
["a", "b"].indexOf("b");       // 1
["a", "b"].indexOf("z");       // -1  (not found)
⚠️ includes uses === — it won't find objects by content, only by reference.
[{a:1}].includes({a:1}) → false (different reference).
Use .some() for object matching: arr.some(o => o.a === 1).

8. Slice, splice, concat, flat

▼
slice — extract a portion (does NOT mutate)
const arr = [1, 2, 3, 4, 5];

arr.slice(1, 3);      // [2, 3]    (indices 1 to 2)
arr.slice(2);         // [3, 4, 5] (from index 2 to end)
arr.slice(-2);        // [4, 5]    (last 2 elements)
arr.slice();          // [1,2,3,4,5]  (shallow copy)
splice — insert/remove at index (MUTATES!)
const arr = [1, 2, 3, 4, 5];

arr.splice(1, 2);           // removes 2 elements from index 1
// arr = [1, 4, 5]

arr.splice(1, 0, "x", "y"); // insert at index 1, remove 0
// arr = [1, "x", "y", 4, 5]

// ⚠️ splice MUTATES. Prefer slice + spread for immutability.
concat — merge arrays (returns new)
[1, 2].concat([3, 4]);        // [1, 2, 3, 4]
[1, 2].concat(3, 4, [5]);     // [1, 2, 3, 4, 5]

// Modern equivalent (usually preferred):
[...arr1, ...arr2];
flat & flatMap — flatten nested arrays
[[1, 2], [3, 4]].flat();          // [1, 2, 3, 4]
[[1, [2, [3]]]].flat(2);          // [1, 2, [3]]  (depth = 2)
[[1, [2, [3]]]].flat(Infinity);   // [1, 2, 3]    (all depths)

// flatMap = map + flat(1)
[1, 2, 3].flatMap(x => [x, x * 10]);
// [1, 10, 2, 20, 3, 30]

9. Update an array immutably

▼

Same rule as objects — return a NEW array instead of mutating.

Add to end / start
const newArr = [...arr, newItem];        // add to end
const newArr = [newItem, ...arr];        // add to start
Insert at index
const newArr = [
  ...arr.slice(0, index),
  newItem,
  ...arr.slice(index)
];
Remove by value
const newArr = arr.filter(item => item !== toRemove);
Remove by index
const newArr = [
  ...arr.slice(0, index),
  ...arr.slice(index + 1)
];

// Or filter by index:
const newArr = arr.filter((_, i) => i !== index);
Update an object inside an array
const newArr = arr.map(item =>
  item.id === targetId
    ? { ...item, name: "New name" }   // update this one
    : item                             // keep others as-is
);
⚠️ These mutate — avoid in React: push, pop, shift, unshift, splice, sort, reverse, fill.

These return new arrays: map, filter, slice, concat, flat, flatMap, spread.

10. Dedupe & Set tricks

▼
Remove duplicates from primitive array (one-liner)
const unique = [...new Set([1, 2, 2, 3, 3, 4])];
// [1, 2, 3, 4]
Dedupe array of objects by a key
const uniqueUsers = [...new Map(
  users.map(u => [u.id, u])
).values()];
// Keeps last occurrence of each id.
Get intersection of two arrays
const common = a.filter(x => b.includes(x));
// For large arrays, convert `b` to a Set first for speed:
const setB = new Set(b);
const common = a.filter(x => setB.has(x));
Get difference
const onlyInA = a.filter(x => !b.includes(x));
Convert Set back to array
const arr = [...mySet];
// or
const arr = Array.from(mySet);

11. Sort recipes — memorize these 6

▼

Rule: sort() takes a comparator (a, b) => number.
Return negative → a comes first. Positive → b comes first. 0 → equal.
⚠️ It MUTATES. Copy first with [...arr] or arr.slice().

1. Numbers — ascending
[3, 1, 5, 2].sort((a, b) => a - b);
// [1, 2, 3, 5]
2. Numbers — descending
[3, 1, 5, 2].sort((a, b) => b - a);
// [5, 3, 2, 1]
3. Strings — alphabetical
["banana", "apple", "cherry"].sort((a, b) => a.localeCompare(b));
// ["apple", "banana", "cherry"]
4. Objects — by numeric field
users.sort((a, b) => a.age - b.age);        // ascending age
users.sort((a, b) => b.totalSpent - a.totalSpent);  // descending spend
5. Objects — by string field
users.sort((a, b) => a.name.localeCompare(b.name));
6. Nulls go LAST (the pattern from Task 9)
items.sort((a, b) => {
  if (a.rating === null) return 1;      // a goes after
  if (b.rating === null) return -1;     // a goes before
  return b.rating - a.rating;            // both non-null: descending
});
Bonus: multi-field sort (sort by dept, then by name)
users.sort((a, b) =>
  a.dept.localeCompare(b.dept) ||    // primary sort
  a.name.localeCompare(b.name)       // tiebreaker
);
// Trick: || returns the first non-zero result.
💡 Avoid mutation with: [...users].sort(...) or the modern users.toSorted(...) (ES2023).

13. Split & join

▼
Split a string into an array
"a,b,c".split(",");          // ["a", "b", "c"]
"hello world".split(" ");    // ["hello", "world"]
"abc".split("");             // ["a", "b", "c"]   ← split into characters
"a,b,c".split(",", 2);       // ["a", "b"]        ← limit result
Join an array into a string
["a", "b", "c"].join(",");     // "a,b,c"
["a", "b", "c"].join(" - ");   // "a - b - c"
["a", "b", "c"].join("");      // "abc"
Reverse a string (classic trick)
"hello".split("").reverse().join("");    // "olleh"
Count words
"hello world how are you".split(" ").length;   // 5

// Handle multiple spaces:
"hello   world".split(/\s+/).filter(Boolean).length;   // 2

14. Replace & basic regex

▼
Replace one occurrence
"hello world".replace("world", "there");
// "hello there"
Replace ALL occurrences — 3 ways
// Modern (ES2021):
"a-b-c".replaceAll("-", "_");        // "a_b_c"

// Regex with /g flag:
"a-b-c".replace(/-/g, "_");          // "a_b_c"

// Split + join trick (works everywhere):
"a-b-c".split("-").join("_");        // "a_b_c"
Common regex patterns (just enough to be useful)
/hello/         // literal
/hello/i        // case-insensitive
/hello/g        // global (find all)
/\d+/           // one or more digits
/\s+/           // one or more whitespace
/^hi/           // starts with "hi"
/end$/          // ends with "end"
/[abc]/         // any one of a, b, c
/[^abc]/        // NOT any of a, b, c
/./             // any single char
Useful regex examples
// Test if match exists:
/\d/.test("abc123");                 // true

// Extract all matches:
"call 123 or 456".match(/\d+/g);     // ["123", "456"]

// Replace with a function (dynamic):
"a1 b2".replace(/\d/g, d => d * 2);  // "a2 b4"

15. Template literals

▼
The basic backtick syntax
const name = "Parth";
const age  = 25;

// Old way:
"Hello, my name is " + name + " and I am " + age + " years old.";

// Template literal:
`Hello, my name is ${name} and I am ${age} years old.`;
Multi-line strings
const html = `
  <div>
    <h1>${title}</h1>
    <p>${content}</p>
  </div>
`;
// No need for \n or string concatenation.
Expressions inside ${...}
`2 + 2 = ${2 + 2}`;               // "2 + 2 = 4"
`Total: ${items.length} items`;    // Total: 5 items
`${age >= 18 ? "adult" : "minor"}`; // ternary works

16. Nullish coalescing (??), Optional chaining (?.), Logical OR (||)

▼
|| — logical OR: falls back on ANY falsy value
const name = user.name || "Guest";
// Falls back to "Guest" if user.name is: undefined, null, "", 0, false, NaN
?? — nullish coalescing: falls back ONLY on null/undefined
const count = user.count ?? 10;
// Falls back to 10 ONLY if user.count is null or undefined
// If user.count is 0, it STAYS 0 (unlike ||)
⚠️ The classic || bug: const qty = input.qty || 1;
If user enters 0 as quantity, this becomes 1! Because 0 || 1 = 1.
Fix: use ??. 0 ?? 1 = 0. ✅
?. — optional chaining: safely access nested properties
const city = user?.address?.city;
// If user is null/undefined → returns undefined (no error)
// If address is null/undefined → returns undefined
// Otherwise → returns city
Optional chaining with method calls & arrays
user?.getFullName?.();       // safely call method if it exists
users?.[0]?.name;            // safely access array item
callback?.();                // call callback only if it's defined
Combine ?. and ?? — the "safe default" pattern
const city = user?.address?.city ?? "Unknown";
// Safely walk the chain, fallback to "Unknown" if anything is null/undefined.
??= — assign only if nullish (ES2021)
acc[key] ??= [];   // if acc[key] is null/undefined, set to []
acc[key].push(item);

// Equivalent to:
if (acc[key] == null) acc[key] = [];

17. Truthy / Falsy values — memorize this

▼
Only 6 values are FALSY in JavaScript. Everything else is truthy — including "0", "false", [], and {}.
Falsy valueNotes
falseThe boolean itself
0, -0, 0nNumeric zero (and BigInt zero)
"" (empty string)Also '' and ``
nullIntentional absence of value
undefinedVariable exists but no value
NaN"Not a Number" (from bad math)
Common surprises
Boolean([]);          // true   ← empty array is truthy!
Boolean({});          // true   ← empty object is truthy!
Boolean("0");         // true   ← string "0" is truthy!
Boolean("false");     // true   ← string "false" is truthy!
Boolean(null);        // false
Boolean(0);           // false
Boolean("");          // false
The Boolean filter trick — remove falsy values from array
[0, 1, "", "hi", null, "foo", undefined].filter(Boolean);
// [1, "hi", "foo"]

18. Parse & format numbers

▼
String → Number
Number("42");          // 42
Number("4.5");         // 4.5
Number("");            // 0    ⚠️ surprise
Number("abc");         // NaN

parseInt("42");        // 42
parseInt("4.9");       // 4    ⚠️ truncates decimals!
parseInt("42px");      // 42   ← stops at non-numeric

parseFloat("4.9px");   // 4.9
parseFloat("abc");     // NaN

+"42";                 // 42   ← the unary + trick, shortest form
+"4.5";                // 4.5
Number → String
String(42);           // "42"
(42).toString();      // "42"
`${42}`;              // "42"    ← template literal

(3.14159).toFixed(2); // "3.14"   ⚠️ returns STRING, not number!
+(3.14159).toFixed(2); // 3.14    ← back to number
parseFloat((3.14159).toFixed(2)); // 3.14
Check for NaN
Number.isNaN(NaN);          // true  (safest)
Number.isNaN("abc");        // false ← the string isn't NaN, it's a string

isNaN("abc");               // true  ⚠️ coerces first, be careful
⚠️ Common bugs:
• parseInt(4.7) = 4 (truncates)
• Number("") = 0 (not NaN)
• .toFixed() returns a string, not a number
• 0.1 + 0.2 === 0.3 → false (floating point). Use a tolerance: Math.abs(sum - 0.3) < 0.001

19. Math methods you'll actually use

▼
Rounding
Math.round(4.4);     // 4     (nearest)
Math.round(4.5);     // 5
Math.floor(4.9);     // 4     (down)
Math.ceil(4.1);      // 5     (up)
Math.trunc(4.9);     // 4     (remove decimals, keep sign)
Math.trunc(-4.9);    // -4
Min / Max
Math.max(1, 5, 3);              // 5
Math.min(1, 5, 3);              // 1

// From an array:
Math.max(...[1, 5, 3]);         // 5
Math.min(...[1, 5, 3]);         // 1
Random
Math.random();                       // 0 to less than 1
Math.floor(Math.random() * 10);      // 0 to 9

// Random integer in range [min, max]:
const rand = (min, max) =>
  Math.floor(Math.random() * (max - min + 1)) + min;
rand(1, 6);   // dice roll (1 to 6)
Absolute value, power, sqrt
Math.abs(-5);       // 5
Math.pow(2, 3);     // 8   (2^3)
2 ** 3;             // 8   (modern equivalent)
Math.sqrt(16);      // 4

20. Common patterns — steal these

▼
Group by key
const grouped = arr.reduce((acc, item) => {
  const key = item.category;
  acc[key] ??= [];
  acc[key].push(item);
  return acc;
}, {});
Count occurrences
const count = arr.reduce((acc, item) => {
  acc[item] = (acc[item] || 0) + 1;
  return acc;
}, {});
// ["a","b","a","c","a"] → { a: 3, b: 1, c: 1 }
Sum a numeric field
const total = items.reduce((sum, i) => sum + i.price, 0);
Find max/min by field
const oldest = users.reduce(
  (max, u) => u.age > max.age ? u : max,
  users[0]
);
Convert array of objects → object indexed by key
const byId = users.reduce((acc, u) => {
  acc[u.id] = u;
  return acc;
}, {});
// { u1: {...}, u2: {...}, ... }
// Now you can look up any user in O(1) by id.
Zip two arrays into pairs
const names = ["a", "b", "c"];
const ages  = [25, 30, 35];

const zipped = names.map((n, i) => [n, ages[i]]);
// [["a",25], ["b",30], ["c",35]]
Chunk an array into groups of N
function chunk(arr, size) {
  const result = [];
  for (let i = 0; i < arr.length; i += size) {
    result.push(arr.slice(i, i + size));
  }
  return result;
}
chunk([1,2,3,4,5,6,7], 3);   // [[1,2,3], [4,5,6], [7]]
Range 0..n-1
Array.from({ length: 5 }, (_, i) => i);
// [0, 1, 2, 3, 4]

Array.from({ length: 5 }, (_, i) => i * 2);
// [0, 2, 4, 6, 8]
Merge multiple objects
const merged = Object.assign({}, obj1, obj2, obj3);
// or
const merged = { ...obj1, ...obj2, ...obj3 };
// Later objects override earlier ones on conflicts.
Pick specific keys from an object
function pick(obj, keys) {
  return keys.reduce((acc, key) => {
    if (key in obj) acc[key] = obj[key];
    return acc;
  }, {});
}
pick(user, ["name", "email"]);
// { name: "Parth", email: "..." }
Omit specific keys from an object
function omit(obj, keys) {
  return Object.fromEntries(
    Object.entries(obj).filter(([k]) => !keys.includes(k))
  );
}
omit(user, ["password"]);

22. Problem-solving method — 5 steps before you code

▼
Don't touch the keyboard until Step 3 is done. This is the single biggest skill separating rushed hacky code from clean solutions.

Step 1 — Say the input and output in one sentence

"I have X, I need to return Y in the shape of Z."
Doing this in English slows your brain enough to catch what you don't understand.

Step 2 — Draw the output shape

// Output:
// [
//   { id, name, reviewCount, avgRating },  // avgRating null if no reviews
//   ...
// ]
// Sorted by avgRating desc, nulls last

Step 3 — Break into independent sub-problems

// A: For each product, find its reviews.
// B: Compute reviewCount + avgRating for each.
// C: Handle "no reviews" case.
// D: Sort with null-last.

Step 4 — For each sub-problem, ask "which HOF fits?"

TaskTool
Same length transformmap
Keep some, drop othersfilter
Collapse to one valuereduce
Side effect onlyforEach
Find onefind
Any/all checksome/every

Step 5 — Now write code

The code becomes translation, not thinking-while-typing. Each sub-problem = one small block.

💡 The bridge trick: Write the sub-problems as comments first, then fill in the code under each. This way, "planning" and "typing" don't fight for your attention at the same time.

The bigger point

You'll feel dumb comparing your first draft to someone else's final draft. That's not a fair comparison. Every experienced dev writes messy code first, then refactors. The difference isn't intelligence — it's exposure. You've written this pattern 3 times; they've written it 300. Speed and elegance come with reps.
